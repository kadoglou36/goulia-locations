# Γουλιά

Mobile-first παρουσίαση για τους φυσικούς σπιτικούς χυμούς Γουλιά, με αρχική σελίδα, πλήρες μενού πλοήγησης και προβολή σημείων πώλησης από το `data.json`.

## Περιεχόμενα

- Η δημόσια σελίδα περιλαμβάνει αρχική σελίδα και πλήρες hamburger μενού.
- Τα «Πού θα μας βρεις» ομαδοποιεί τα καταστήματα ανά περιοχή.
- Υπάρχει αναζήτηση και φίλτρα για Αττική και Εύβοια.
- Κάθε σημείο ανοίγει αναζήτηση Google Maps.

## Τοπική εκτέλεση

```powershell
python -m http.server 8765
```

Άνοιξε το `http://localhost:8765`.

## Διαδρομές

- `/homepage` — αρχική
- `/products` — προϊόντα
- `/locations` — σημεία πώλησης
- `/about` — σχετικά με εμάς
- `/vision` — όραμα
- `/blog` — blog
- `/contact` — επικοινωνία

Οι διαδρομές αλλάζουν μέσω του browser History API μέσα από το μοναδικό `index.html`.

## Σημαντικό για το GitHub JSON

Τα `index.html`, `style.css` και `data.json` είναι στατικά αρχεία. Ο browser δεν μπορεί με ασφάλεια να γράψει στο GitHub ή να κρατήσει μυστικό GitHub token.

Για πραγματικό login και αποθήκευση στο GitHub χρειάζεται μικρό ασφαλές backend ή serverless endpoint που:

1. κάνει authentication του ιδιοκτήτη,
2. επικυρώνει τα πεδία της νέας εγγραφής,
3. ενημερώνει το `data.json` μέσω GitHub Contents API με token σε secret,
4. επιστρέφει στη σελίδα το νέο JSON.

Έτσι οι επισκέπτες παραμένουν μόνο σε read-only δημόσια προβολή.
