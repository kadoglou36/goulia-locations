# Γουλιά - Σημεία πώλησης

Μικρή mobile-first σελίδα για τους χυμούς Γουλιά, με τα σημεία πώλησης από το PDF σε `data.json`.

## Περιεχόμενα

- Η δημόσια σελίδα ομαδοποιεί τα καταστήματα ανά πόλη.
- Υπάρχει αναζήτηση και φίλτρα για Αττική και Εύβοια.
- Κάθε σημείο ανοίγει αναζήτηση Google Maps.
- Το `?admin=1` ανοίγει το UI διαχείρισης για προσθήκη σημείου στη συγκεκριμένη συνεδρία.

## Τοπική εκτέλεση

```powershell
python -m http.server 8765
```

Άνοιξε το `http://localhost:8765`.

## Σημαντικό για το login και το GitHub JSON

Τα `index.html`, `style.css` και `data.json` είναι στατικά αρχεία. Ο browser δεν μπορεί με ασφάλεια να γράψει στο GitHub ή να κρατήσει μυστικό GitHub token. Το τωρινό admin UI είναι frontend prototype και οι νέες εγγραφές ζουν μόνο στη μνήμη της ανοιχτής σελίδας.

Για πραγματικό login και αποθήκευση στο GitHub χρειάζεται μικρό ασφαλές backend ή serverless endpoint που:

1. κάνει authentication του ιδιοκτήτη,
2. επικυρώνει τα πεδία της νέας εγγραφής,
3. ενημερώνει το `data.json` μέσω GitHub Contents API με token σε secret,
4. επιστρέφει στη σελίδα το νέο JSON.

Έτσι οι επισκέπτες παραμένουν μόνο σε read-only δημόσια προβολή.
